# Windows Scripts

This directory contains the native Windows build and run scripts. Prefer the
terminal commands in `..\bin` after running `..\bin\activate.cmd` or
`.\activate.ps1` from this directory.

Primary commands:

- `makenek`
- `nek`
- `nekmpi`
- `genmap`
- `genbox`

See `..\README-Windows.md` for exact setup, build, and smoke-test commands.
